## 一、P0：信任启发式检测（最直接的价值增量）

trustcheck malicious.py 有 6 种检测启发式。其中 3 种只需要 PyPI JSON API 公开 metadata。

### H1: Release Cadence 检测（trustcheck malicious.py L921-1019）

检测发布频率异常。

| 检测 | 条件 | 分数 |
|---|---|---|
| release_burst | 24h 内 >=5 版本 | 20 |
| release_after_dormancy | 距上次 >=365 天 | 22 |
| release_cadence_acceleration | 当前间隔 <=1h 且中位数 >=7 天 | 18 |

数据来源：PyPI JSON API GET /pypi/{project}/json -> releases -> upload_time

实现：canari/cadence.py 新文件
- analyze_release_cadence(project, current_version) -> list of findings
- 新检查 ID: L2.4_RELEASE_CADENCE
- 无异常 pass / 命中 pass-with-findings / API 错误 unsupported
- 接入 build_attestation() 在 native_provenance 之后

工时 3h

### H2: Metadata Anomaly 检测（trustcheck malicious.py L844-918）

检测与上一次 release 相比的身份/仓库变化。

| 检测 | 分数 | 信号 |
|---|---|---|
| maintainer_identity_change | 24 | author/maintainer 变了 |
| project_ownership_change | 35 | owner/organization 变了 |
| declared_repository_change | 38 | 仓库 URL 完全不重叠 |

实现：canari/anomaly.py 新文件
- 需要 state.py 扩展：存 maintainers + homepage
- 新检查 ID: L2.5_METADATA_ANOMALY

工时 4h

### H3: Typosquatting 检测（trustcheck malicious.py L758-803）

检测包名与可信项目异常相似。

trustcheck 用 Damerau-Levenshtein + compact name（去-）+ 自适应阈值。

实现：canari/typosquat.py 新文件
- 需要 PyPI top-N 包名作为可信集
- 新检查 ID: L2.6_TYPOSQUATTING

工时 3h
