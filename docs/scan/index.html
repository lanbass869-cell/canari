Re-derive it yourself

A signature only proves who signed. To check that the signed verdict actually matches what the scanner said, recompute it:

python verify.py

That script does not import this project. It re-implements three checks from scratch: the DSSE/Ed25519 signature, the artifact digest binding, and the verdict derived straight from inputs/*.bandit.json. MANIFEST.json maps each package to its raw scanner output, its artifact sha256 and its record.

Verified negative control: downgrading the two HIGH findings in one raw report makes it fail with both a digest mismatch and a verdict mismatch, exit code 1.

Verify it yourself

No account, no network to us, no trust required.

pip install canari-mcp
# public key
curl -O <url>/public_key.json
# any record
canari-verify <record>.bundle.json --key public_key.json
