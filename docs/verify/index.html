Canari log verifier

Checks a Canari log bundle in your browser. Nothing is uploaded and no network request is made: open this page, drop a bundle, read the result. The same checks exist as a Python script and a Node script in the repository; three implementations disagreeing would itself be a finding.

Drop a bundle JSON here, or click to choose a file

What a passing result means: the tree head was signed by the key in the bundle; the entry is in that tree; a later head still contains the earlier one. It does not mean the data inside the record is true. Format: docs/spec/append-only-log.md.
