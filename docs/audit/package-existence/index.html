What this measures. The registry checks a package version when it is published and does not check it again. This resolves every npm/PyPI package reference in the latest snapshot against the publisher's own registry, one request per package, and lists the ones that cannot be installed today. A removed package is usually an unpublish, rename, yank or abandonment — this is not a security report, and a missing version is not evidence of malice. Entries using a dist-tag such as latest are counted separately, not as missing versions.
