# Agent 前沿第一批：两个理论锚点与一个可能的缝

2026-11-18。读了两篇全文（不是摘要），记录"证明了什么 / 假设是什么 / 它自己说下一步是什么"。

## 锚点 1：arXiv:2512.07631《The Agent Capability Problem》(2025-12)

**它证明了什么**

把 agent 解题看成信息获取：需要 `I_total` 比特，每步获得 `X_i` 比特、代价 `C_s`。
在三条假设下：

1. 条件独立（给定历史）
2. 二阶矩有界 `sup E[X_i²] < ∞`
3. **递减收益** `μ_1 ≥ μ_2 ≥ … ≥ μ_inf > 0`

**定理 3.1（双边界）**：

```
C_eff ≤ E[C] ≤ C_s · ( I_total/μ_inf + M²/μ_inf² )
```

**它自己说下一步**（原文）：
> "Future work includes exploring **multi-agent coordination**, **dynamic environments**,
> and **tighter surrogate models** tailored to specific problem classes."

**假设里最脆的一处**：递减收益 + 条件独立。真实 agent 的信息增益是**由策略决定的**，
可以因一次幸运发现而变高，也可能被外部输入（提示、工具返回、注入）**主动压下去**。
这个假设一破，双边界的方差项 `M²/μ_inf²` 就失去意义。

## 锚点 2：arXiv:2606.27567《On the Inseparability of Instructions and Data》(2026-06)

**它证明了什么**

在**共享嵌入架构**（无强制控制-数据分离）下，完美的 prompt-injection 防护**数学上不可能**。
五条引理支撑：表示碰撞、表示不忠实、**provenance-recovery 不可能性**（以 total variation 距离界定）、
控制路径暴露、有限覆盖不变性间隙。

**它明确划的界**：强制执行控制-数据分离的架构不在范围内。

**一个对我们很重要的旁证**：作者是 **Independent Researcher**（Dewank Pant）。
**个人研究者在这个前沿是能发出形式化结果的。**

## 把两篇接起来：一个可能的缝

| | 锚点 1（ACP） | 锚点 2（不可分离） |
|---|---|---|
| 问的是 | 资源够不够解出任务 | 注入能不能被完美防住 |
| 假设 | 增益非对抗、递减 | 共享嵌入、无控制分离 |
| 结论形态 | 定量双边界 | 定性不可能性 |

**两篇之间是空的**：没有人把"**攻击者压低信息增益**"这件事，接到**能力估计**上。

### 候选 F：能力 vs 攻击的可识别性

> 一个 agent 表现差，是因为**它弱**（μ 低），还是因为**它被攻击**（增益被外部压制）？
> 在只看输出的条件下，这两者能否被区分？

**为什么这可能是真缝**：

1. ACP 假设增益非对抗，**无法表达"被压制"**
2. 不可分离定理说防护不可能，但**不给任何成本/收益的量化**（"防不住"≠"能测出来"）
3. 这个问题的形态是**可识别性（identifiability）**：两类世界在观测上是否可区分

**预期的定理形态（假设，未证）**：

> 给定仅观测总代价 C 与总增益，存在一对（低能力, 无攻击）与（高能力, 被压制）的参数，
> 使两者的观测分布**在统计上不可区分**，除非对增益过程有基线测量。
> ⇒ **没有基线，就没有可用的"被攻击"告警。**

**这个结论如果成立，其价值**：它给"agent 监控 / 异常检测"这条工程线划了一条理论边界——
你现在看到的"agent 变笨了"，在数学上无法区分于"它本来就笨"。

## 为什么这个比之前的候选好

| 维度 | 候选 A（扣留） | 候选 F（可识别性） |
|---|---|---|
| 所依赖文献年龄 | 1999–2026 累积 | **0–12 个月** |
| 是否已被做掉 | 是（folklore） | 未见（两篇都未涉及对方） |
| 我们能否验证 | 可以（但结论已知） | 可以（形式化 + 仿真） |
| 出版形态 | 弱 | 短论文 / workshop 可投 |
